#  Линейная регрессия - Прогноз продаж мороженого

##  Описание проекта

Это веб-приложение, которое предсказывает прибыль от продажи мороженого в зависимости от температуры воздуха.  
Проект использует **линейную регрессию** (машинное обучение с учителем) для прогнозирования.

### Что делает программа:
1. Обучает модель на исторических данных (температура → прибыль)
2. Показывает график зависимости (ваш скриншот)
3. Позволяет ввести температуру и получить предсказание прибыли

---

##  Данные

| Признак (X) | Целевая переменная (y) |
|-------------|------------------------|
| Температура (°F) | Прибыль от продаж ($) |

**Точность модели:** > 97% (R² Score)
